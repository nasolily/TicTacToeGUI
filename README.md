## 🎯 About

**Tic-Tac-Toe GUI** is a Java desktop application built using **Java Swing** to practice graphical user interface development, event-driven programming, and game logic.

The application recreates the classic game of Tic-Tac-Toe in an interactive desktop environment where two players take turns placing Xs and Os. This project manages game state, handles user interactions, and builds a responsive GUI application.

---

## ✨ Features

❌ Two-player Tic-Tac-Toe gameplay

⭕ Interactive game board built with Java Swing

🏆 Automatic win and draw detection

🖱️ Click-based gameplay

🔄 Restart and replay functionality

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/nasolily/TicTacToeGUI
cd TicTacToeGUI
```

### Open the project

Open the project using **IntelliJ IDEA**.

Make sure your Java Development Kit (JDK) is configured before running the application.

### Run the application

Run the main Java class to launch the Tic-Tac-Toe game.
